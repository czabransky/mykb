## Expressing Ability vs Physical Capability

In Chinese, there are two different verbs to express "can": **会** (huì) and **能** (néng).

<CharacterGrid
    characters={[
        { char: '会', pinyin: 'huì', english: 'can (ability)' },
        { char: '能', pinyin: 'néng', english: 'can (physical capability)' },
    ]}
/>

<PatternBox
    pattern={[
        { part: '我', label: 'I' },

        { part: '我', label: 'I' },
        { part: '不能', label: 'cannot (physical capability)' },

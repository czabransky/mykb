# Questions and Time Frames

This concept merges 什么时候 usage with 前 (before/ago) time framing.

<RuleChecklist
    title="Core Rules"
    rules={[
        {
            rule: 'Treat 什么时候 as one lexical chunk meaning "when".',
            why: 'It is not built fresh each time from 什么 + 时候 in usage.'
        },
        {
            rule: '前 can mean either "before" or "ago" depending on position.',
            right: '三点前吃饭。 / 三天前吃了中国菜。'
        },
        {
            rule: 'Use duration classifiers only when needed for clarity.',
            why: 'Use 四个月 for explicit month duration, while 两天 is already clear without a classifier.'
        }
    ]}
/>

<PatternBox
    title="When Question"
    pattern={[
        { part: '你', label: 'you' },
        { part: '什么时候', label: 'when' },
        { part: '____', label: 'verb phrase' },
        { part: '？', label: 'question' },
    ]}
    example={{
        chinese: '你什么时候吃早饭？',
        pinyin: 'nǐ shénme shíhòu chī zǎofàn?',
        english: 'When do you eat breakfast?'
    }}
/>

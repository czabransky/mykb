# Survival Interaction and Shopping

This page focuses on foundational interaction and shopping dialogue patterns.

<RuleChecklist
    title="Core Rules"
    rules={[
        {
            rule: 'Start polite requests with 请问 when asking strangers.',
            right: '请问，这个多少钱？'
        },
        {
            rule: 'Use 这个 / 那个 to point clearly before asking price.',
            right: '这个面包多少钱？'
        },
        {
            rule: 'Price responses are often noun phrases without extra verbs.',

<PatternBox
    title="Polite Price Question"
    pattern={[
        { part: '请问', label: 'polite opener' },

        { part: '？', label: 'question' },
    ]}
    example={{
        chinese: '请问这个多少钱？',

    }}
/>

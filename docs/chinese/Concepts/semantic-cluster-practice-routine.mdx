## Practice Loop

<CardGrid columns={3}>
    <Card title="Step 1: Build Cluster">
        Choose 8-12 words from one theme and link by meaning, not by alphabet.
    </Card>
    <Card title="Step 2: Build Patterns">
        Write one question pattern and two answer patterns with those words.
    </Card>
    <Card title="Step 3: Build Variation">
        Rewrite each sentence with a time phrase, then with a contrast marker like 但是 or 还.
    </Card>
</CardGrid>

## Weekly Output Target

1. Two mini-clusters from old logs.
2. One new paragraph combining both clusters.
3. One correction pass that labels each error as: word choice, grammar frame, or naturalness.

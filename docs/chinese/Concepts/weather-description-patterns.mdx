# Weather Description Patterns

This page focuses on one clear weather decision rule: adjective weather vs noun weather.

<RuleChecklist
    title="Core Rules"
    rules={[
        {
            rule: 'With weather adjectives, do not force 是.',
            right: '今天天气很冷。',
            wrong: '今天天气是很冷。'
        },
        {
            rule: 'With weather nouns (晴天/雨天), 是 is natural.',
            right: '星期一是晴天。'
        },
        {
            rule: 'Use action verbs for events: 下雨, 下雪, 刮风.',
            right: '明天会下雨。'
        }
    ]}
/>

<PatternBox
    title="Baseline Weather Pattern"
    pattern={[
        { part: '今天天气', label: 'today weather' },
        { part: '很', label: 'degree marker' },
        { part: '____', label: 'adjective' },
    ]}
    example={{
        chinese: '今天天气很热。',
        pinyin: 'jīntiān tiānqì hěn rè.',
        english: 'The weather is hot today.'

# 📚 Nouns

Nouns are words that name people, places, things, or ideas. In French, nouns have a **gender** (masculine or feminine)
and a **number** (singular or plural). Understanding these features is essential for correct grammar and agreement.

## Definition & Overview

A **noun** (*un nom*) is a word that identifies a person, place, thing, or idea. In French, every noun has a gender (
masculine or feminine) and a number (singular or plural). This affects the articles and adjectives that accompany the
noun.

---

## Gender of Nouns

Every French noun is either **masculine** or **feminine**. The gender affects articles, adjectives, and pronouns used
with the noun.

### How to Identify Gender

| Ending/Type       | Usually Masculine                      | Usually Feminine                 |
|-------------------|----------------------------------------|----------------------------------|
| -age, -ment, -eau | le fromage, le gouvernement, le bureau |                                  |
| -isme, -oir, -sme | le tourisme, le miroir                 |                                  |
| -é, -teur         | le café, le chanteur                   |                                  |
| -e, -ion          |                                        | la pomme, la nation              |
| -té, -ée, -ie     |                                        | la liberté, la journée           |
| -ure, -ade, -ance |                                        | la voiture, la salade, la chance |

**Note:** There are exceptions! Always check a dictionary if unsure.

#### Visual Aid: Gender Cheat Sheet

| Masculine Endings                         | Feminine Endings                           |
|-------------------------------------------|--------------------------------------------|
| -age, -ment, -eau, -isme, -oir, -é, -teur | -e, -ion, -té, -ée, -ie, -ure, -ade, -ance |

## Pluralization of Nouns

Most French nouns form the plural by adding **-s** to the singular form.

| Singular  | Plural      | Example Sentence                | English Translation |
|-----------|-------------|---------------------------------|---------------------|
| le livre  | les livres  | J'ai acheté deux **livres**.    | I bought two books. |
| la maison | les maisons | Les **maisons** sont anciennes. | The houses are old. |

### Irregular Plurals

Some nouns have irregular plural forms:

| Singular   | Plural      | Example Sentence                         | English Translation               |
|------------|-------------|------------------------------------------|-----------------------------------|
| le cheval  | les chevaux | Les **chevaux** courent dans le champ.   | The horses run in the field.      |
| l’animal   | les animaux | Les **animaux** dorment la nuit.         | The animals sleep at night.       |
| le travail | les travaux | Les **travaux** commencent demain matin. | The work starts tomorrow morning. |

Nouns ending in **-s**, **-x**, or **-z** do not change in the plural:

- **le prix** → **les prix**
- **le nez** → **les nez**

---

## Common Patterns & Exceptions

- Nouns borrowed from other languages are usually masculine.
- Some nouns can be both masculine and feminine, with a change in meaning (e.g., **le livre** = book, **la livre** =
  pound).
- Some professions and roles have both masculine and feminine forms: **un acteur / une actrice**.
- Some nouns are always singular or plural (e.g., **les vacances** is always plural).

---

## Usage Notes & Pitfalls

- Articles and adjectives must agree in gender and number with the noun.
- Gender is not always predictable; memorize with the article (e.g., **la table**, **le problème**).
- Some nouns change meaning depending on gender (e.g., **le tour** = trip, **la tour** = tower).
- When in doubt, consult a dictionary for the correct gender.

## Example Sentences

- **Le chat dort sur le canapé.**  
  (The cat sleeps on the sofa.)
- **La voiture rouge est rapide.**  
  (The red car is fast.)
- **Les enfants jouent dans le jardin.**  
  (The children play in the garden.)
- **J’ai acheté des pommes au marché.**  
  (I bought apples at the market.)
- **Mon ami est médecin.**  
  (My friend is a doctor.)
